--- 3. Model Selection: Unsupervised vs Hybrid I’ve seen teams default to Isolation Forest because it’s simple. That’s a mistake when fraud patterns drift monthly. The best production pipelines I’ve shipped use a two-stage hybrid:

Embedding Stage : Auto-encode claims into 16-dim vectors using a variational autoencoder (VAE). Anomaly Stage : Score the embeddings with a Mahalanobis distance layer that adapts to policy class drift.

Why this combo? VAEs compress sparse bordereaux into dense vectors that preserve semantic similarity (e.g., two “rear-end collision” claims cluster together). Mahalanobis distance normalizes for policy class variance (a $5k claim is an outlier for a $1k deductible policy but normal for a $500 deductible).

In the VAE implementation using PyTorch, the system’s complexity becomes even more pronounced. With an engineered table (claim_features) containing 32 columns—split evenly between numerical and categorical embeddings—the VAE operates as a hub in the value chain, where numerical and embedding features interact through latent space compression. The numerical features introduce stability into the system, while the categorical embeddings, now compressed into dense vectors, introduce variability that the VAE must reconcile. The system responds by balancing reconstruction accuracy with latent space structure, but this balance is fragile: if the embeddings are not well-regularized, the VAE may overfit to spurious patterns, leading to poor generalization on unseen claims. Meanwhile, the choice of a VAE introduces emergent behavior in how anomalies are detected—by reconstructing input data, the model implicitly learns the distribution of "normal" claims, but the system’s response to anomalies depends heavily on the encoder’s ability to capture nuanced patterns in both numerical and embedding data. If the embeddings are not discriminative enough, the VAE may fail to detect subtle drifts in claim characteristics, rendering the anomaly pipeline ineffective. Thus, the VAE’s performance is not just a function of its architecture but of how well the entire system—from embedding generation to latent space learning—aligns to detect and respond to anomalies in real time.

```python import torch import torch.nn as nn import torch.nn.functional as F

class VAE(nn.Module): def __init__(self, input_dim=32, latent_dim=16): super().__init__() self.enc1 = nn.Linear(input_dim, 64) self.enc2 = nn.Linear(64, 32) self.fc_mu = nn.Linear(32, latent_dim) self.fc_var = nn.Linear(32, latent_dim) self.dec1 = nn.Linear(latent_dim, 32) self.dec2 = nn.Linear(32, 64) self.dec3 = nn.Linear(64, input_dim)

def encode(self, x): h = F.relu(self.enc1(x)) h = F.relu(self.enc2(h)) mu, log_var = self.fc_mu(h), self.fc_var(h) return mu, log_var
